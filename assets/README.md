# Synthetic visual assets

All portraits depict fictional generated adults. They illustrate enrollment and staff-photo UI and are not real watchlist subjects. Store views show ordinary shopping/checkout. No pictured person is identified as a shoplifter. The mockup overlays are design demonstrations, not detections from these photos.

The six-panel image was generated using the built-in image-generation tool for this package. Individual panels were extracted for UI use. The original sheet is retained. The prompt is recorded in PROMPT.txt. Do not import these images into production enrollment, training or performance evaluation without a separately defined purpose.
